# SUIBE Campus Hub · 贸大校园服务助手

本地可运行的校园服务 MVP，面向大赛赛道一“经贸与校园赋能智能体”。按项目方选择，默认是 **离线规则工具演示**，预留兼容大模型接入。教室占用、教师、课程、公告为示例；地图与校历为示意。学校系统尚未接入。

## 已实现

新增赛事广场：校内与大型赛事分类、方向筛选、报名状态、官方入口、关注收藏与截止日历导出。来源与人工更新边界见 `docs/赛事广场.md`。

新增校园食光：餐厅/窗口/菜品筛选、审核后公开点评、拍照集邮与探索徽章。手机端新增九宫格服务入口与底部导航，同一 Wi-Fi 预览可用 `./start.ps1 -Mobile`。菜单为示例，照片仅保存在当前浏览器。详见 `docs/校园食光与手机门户.md`。

蓝白改版已加入学校官网校徽、按用户分布图重建的 20 个建筑与原图对照、跟随所选起点的“你在这里”标签，以及有学校原文来源的校园生活指南。更新说明和后续建议见 `docs/蓝白改版与地图更新.md`。

百度地图核验更新：保存新图书馆到学思楼整体点位（270 米）、图文信息楼（160 米）、体育馆（660 米）、乐群楼（520 米）的网页步行结果，无需 Key。地图加入五个公开点位参考、学思楼整体点位选项、常用路线按钮、红色终点和自动取景；其他路线仍为示意。来源、截图与范围见 `docs/百度距离核验与地图优化.md`。

校历更新：录入用户提供的 2026–2027 学年两学期校历，支持周历、事项清单、原图、当前周次，以及离线自动生成窗口、本机保存、ICS/JSON 导出和打印。第一学期从 2026-09-14 开始，共 19 周；首页已替换原示例周次算法。使用说明见 `docs/校历与自动生成使用说明.md`。

首页与搜索、空闲教室列表/楼层/详情、教师查询与纠错、Three.js 校园场景与路线、匿名点评提交和审核闭环、本地课表及冲突检测、JSON/简单 CSV 备份导入、公告校历、收藏反馈、管理后台和 CSV 导入。

助手任务示例：“今天第3-4节找一间至少40人的自习教室，从图书馆怎么走？”返回工具执行轨迹、来源和页面入口。模型模式在配置完成后使用同一组只读工具。

助手已接入校历查询、按学期周次扣除个人课表后寻找连续空档，以及校历草稿预填。可问“这学期期末考试什么时候开始”，或勾选分享课表后问“根据我的课表找明天下午连续两节空档，推荐40人的教室，并从图书馆导航”。20 条离线任务记录与使用边界见 `docs/助手任务闭环更新.md`。

## 本地启动（Windows）

要求 Python 3.12+、Node 22+、npm。依赖只需首次联网安装，安装完成后无需模型或外部数据库即可演示。

```powershell
python -m venv .venv
./.venv/Scripts/python.exe -m pip install -r backend/requirements.txt
cd frontend
npm ci
cd ..
```

如果系统没有 Python，可使用 Codex 依赖工具返回的 Python 完整路径创建 venv。

终端一（项目根目录）：

```powershell
./.venv/Scripts/python.exe -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8000
```

终端二：

```powershell
cd frontend
npm run dev
```

打开 http://127.0.0.1:5173 。API 文档在 http://127.0.0.1:8000/docs 。结束时各终端按 Ctrl+C。也可运行 `./start.ps1` 隐藏启动，它会打印本次进程 ID，结束时仅停止这两个进程。

## 后台与模型配置

复制 `.env.example` 为 `.env`，设置一个随机 `ADMIN_TOKEN`。后端启动时自动加载文件，已有进程环境变量优先；改动后重启后端。管理员访问 `/admin` 输入凭证。不要把管理凭证或模型密钥发到聊天里或提交 Git。

本地默认会生成被 Git 忽略的 `.local-secret`，用于邮箱和凭证摘要。不要删除该文件，否则既有点评的管理凭证和邮箱限次无法匹配。生产部署使用持续保存的 `APP_SECRET`。

模型接入：在后端环境设置 `LLM_API_KEY`、`LLM_MODEL`，以及服务商 `LLM_BASE_URL`（须包含 `/v1` 等相应 API 前缀）。默认采用兼容 Chat Completions 的工具调用协议，真实服务尚待配置测试。不配置则自动使用离线模式。

## 数据导入

`data/` 下提供教室、占用、教师、课程、课表模板。管理后台粘贴或上传 CSV，先校验再按 ID 更新。用真实数据覆盖示例教室时需要同时导入匹配的占用表；没有占用数据的导入教室会被视为空闲，因此对外发布前必须确保占用数据完整且及时。当前没有实时学校接口或自动教师爬虫。

课表 JSON 导入会替换整个本地课表，建议先备份。简单 CSV 不支持字段内逗号/引号，周次使用 `1-16`。支持 1–14 节、周次区间与多学期，不支持 Excel、拖拽或云同步。点评管理凭证存浏览器，可在个人中心备份。

已准备 GitHub + Render Free + Neon Free 的部署文件：`render.yaml`、`deploy/Dockerfile`。按 `docs/免费云部署.md` 连接账号后发布；目前配置准备不等于上线。使用外置 PostgreSQL 持久保存数据，免费网站会休眠。

## Docker 部署

在 `.env` 补充 `POSTGRES_PASSWORD`（建议纯字母数字随机字符串）、`APP_SECRET`、可选 `ADMIN_TOKEN`：

```powershell
docker compose up --build -d
```

打开 http://127.0.0.1:8080 。PostgreSQL 使用持久卷，后端不暴露端口，Nginx 代理 API 并支持 SPA 路由刷新。Docker 路径已提供，尚未在当前机器运行验证。公开发布前配置 HTTPS、经验证的身份、持久限流、完整审核和真实数据来源；当前服务是本地演示。
