# 蓝白主题与校园地图更新

后续更新：已从百度地图核验并离线保存四条步行距离；本文件后半部分“尚未取得固定距离”的记录是此前高德检索结果。当前实现和数据范围见 [百度距离核验与地图优化](百度距离核验与地图优化.md)。

## 本次实现

- 全站改为蓝白色：导航、按钮、卡片、助手、课表、搜索、原图入口与地图侧栏统一色调，并提高原有小字号的可读性。
- 校徽使用学校官网“标识系统”公开图像中的蓝色版本，保留原始文件，使用 CSS 显示对应区域；不是 AI 重绘校徽。左侧品牌与首页水印均采用同一校徽。
- 根据用户提供的分布图重建 20 个建筑：学思楼 A–D 沿用红字标记顺序，补充四座学院楼、餐厅、行政及文化建筑、体育馆；重建思源湖、水景、运动区与相对路网。
- 增加 3D / 原图对照、建筑检索、设为起终点、教学楼到教室筛选、餐厅到生活指南等联动。选择建筑或规划路线时保留相机，避免每次重建场景。
- 起点增加蓝色位置圈、竖向标记和“起点 · 你在这里”标签；原图对照也显示该标签。标签跟随用户选定起点，不读取设备定位，也不声称识别到了实际位置。
- 按补充反馈，学思楼使用四条平行楼体、前后连通部分与三处连续拱洞；移除每栋重复添加的两侧翼与小拱门，避免误看成多个独立楼群。
- 新增 7 条生活指南，覆盖报修、餐饮、通勤、收货和社区空间；注明原文与发布时间，提供原文链接。助手与全站搜索可以检索这些内容。
- 首页补充生活指南入口和官方办事入口；教室页保留用户提供的学校查询链接，同时明确实时数据尚未接入。

## 地图更新与数据保护

原版地图是自由摆放的示意数据。本次布局版本为 `reference-map-v5`。后端启动检测到原版或旧版地图时，先把旧地图写入 `map_backup / before-reference-map-v5`，再更新地图相关目录；课表、教室、课程、点评和反馈不清空。课表仍在浏览器本地。

相对坐标通过原图建筑中心点转换为世界坐标；渲染高度与入口为示意，不是实测楼层与门禁。没有地理比例尺，界面显示的长度、分钟数不能作为实际导航依据。原图中的校门未核验正式名称，显示“校门（原图）”；不再把未证实的卫生间、电梯与无障碍条件作为地图实况。

## 后续优先更新建议

1. **校方数据接入**：优先拿到获准使用的日期、节次、教室占用数据，再扩展真实教师和课程资料。实时状态必须显示更新时间、来源及更新失败状态。
2. **实地地图校准**：记录常用建筑门口、校园路口、比例尺、无障碍条件、开放时间；优先校核图书馆→学思楼、教学楼→餐厅两条演示路线。
3. **生活信息维护**：给指南设置负责人、核验日期、失效日期与纠错入口；把图片内服务时间、地址、电话转成有来源的结构化字段后人工复核。
4. **真正的智能体评测**：接入模型后用相同任务比较规则模式与模型工具模式，记录参数准确性、澄清、任务成功率和来源可靠性。

现阶段不建议先堆更多模块，优先把已有功能的数据可信度、地图精度与真实任务完成率做好。
