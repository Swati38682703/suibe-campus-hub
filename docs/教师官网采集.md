# 教师官网资料采集

范围依据学校官网“教研单位”页面 https://www.suibe.edu.cn/7351/list.htm 核对。实际学院入口、师资目录及补充职称栏目保存于 data/teacher_sources.json；本次数据及各学院状态保存于 data/teachers_official.json。

采集仅访问学校公开HTTPS来源并遵守robots规则。对页面自身公开使用的teacherHome目录，沿用language=1和published=1条件及公开分页，只读取页面使用的姓名、职称/岗位、公开邮箱、办公地点、系所及个人主页链接。静态师资目录限定在教师表格、教师列表及其公开分页，不从新闻报道推断任职。单次请求限制2MB，最低请求间隔0.5秒，个人主页最多2个并发。

个人主页只补充有明确表述的研究方向、邮箱、办公地点及职称，不保存完整简历、手机号、出生日期或私人信息。缺失字段留空，访问失败保留已核对目录字段。不同主页的同名人员不直接合并，相同主页在同一学院内去重；这是公开资料条目数，不是唯一在职教师人数。

教师页面、详情、全站检索与贝贝的search_campus使用同一份资料。正式官网条目存在时不展示旧的虚构示例教师，但不删除原数据库；保留非示例的人工导入记录。前端每次显示24条，筛选在浏览器内完成，来源面板展示各学院采集数量、状态与个人主页读取情况。未找到公开目录的学院明确标注，不假造教师。

线上已开启半年更新：网站进程每6小时检查一次，到每年1月15日、7月15日后执行当期更新。免费实例休眠时不会运行，下一次访问唤醒服务后会立即在后台补跑。新结果至少需要700条记录、10个成功学院且来源计数一致，才会原子替换数据库中的上一版；失败会记录状态但保留上一版。设置 `TEACHERS_SYNC_ENABLED=0` 可停用。

人工重新采集命令：

    pip install -r backend/requirements.txt
    python -m backend.app.teacher_crawler --output data/teachers_official.json

可用--cache指定本次任务的断点续采目录，后续更新应使用新的空目录或不传该参数，避免复用旧页面。自动更新成功后写入共享数据库，所有访问者共享服务器资料。公开页面也可能滞后，不能把采集时间称为教师资料的官方变更时间。
