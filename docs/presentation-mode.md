# 学校展示模式

用户明确要求先不做账号密码，只切换角色展示不同页面。

- 用户入口：首页卡片或顶部“用户视图”。
- 管理员入口：`/admin`，无需登录。支持赛事、食堂、公告的新增、修改、隐藏、恢复及按栏目重置。
- 保存于 `localStorage` 的 `suibe-demo-content-*`，仅当前浏览器可见；同浏览器标签页会同步。
- 角色以页面入口区分，仅为展示，不代表真实身份或权限。
- 原服务器后台保留在 `/admin/server`，仍要求服务器 ADMIN_TOKEN；没有放宽任何后端授权。
- 演示新增菜品支持本地拍照集邮，不可向真实点评接口提交不存在的菜品。
- 原有课表、收藏、照片及点评凭证使用独立存储键，重置演示编辑不删除这些数据。
- 未启用 Neon Auth，未创建账号、密码或身份基础设施。
