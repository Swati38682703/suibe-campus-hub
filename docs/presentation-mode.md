# 学校展示模式

用户明确要求先不做账号密码，只切换角色展示不同页面。

- 用户入口：顶部“用户视图”；首页不再重复放置入口卡片。
- 管理员入口：`/admin`，无需登录。支持赛事、食堂、教师、公告的新增、修改、隐藏、恢复及按栏目重置。
- 保存于 `localStorage` 的 `suibe-demo-content-*`，仅当前浏览器可见；同浏览器标签页会同步。
- 角色以页面入口区分，仅为展示，不代表真实身份或权限。
- 原服务器后台保留在 `/admin/server`，仍要求服务器 ADMIN_TOKEN；没有放宽任何后端授权。
- 演示新增菜品支持本地拍照集邮，不可向真实点评接口提交不存在的菜品。
- 原有课表、收藏、照片及点评凭证使用独立存储键，重置演示编辑不删除这些数据。
- 未启用 Neon Auth，未创建账号、密码或身份基础设施。

- 教师管理可维护姓名、拼音、学院、职称、邮箱、办公室、研究方向及来源；用户搜索与筛选使用修改后的资料。
- 空教室入口使用学校 aws.suibe.edu.cn 的 echartHt.html 页面，本站筛选仍明确标为演示，未声称同步实时占用。

- 管理员工作台增加“课程点评审核”。该栏目使用现有 ADMIN_TOKEN 访问服务器真实待审、已通过及隐藏点评；凭证仅存在组件内存，不写入浏览器存储。审核通过会真实公开，隐藏会移出公开统计。展示角色切换本身不授权。
