# 空闲教室加载优化

页面按日期读取一次全日教室快照，忽略接口预计算的available字段，根据busy与用户所选节次在页面重新计算。楼栋、容量、类型和房号筛选在本地执行，不因输入每个字或切换节次重新请求。全部教学楼与全部占用数据仍需完整读取，避免将未返回的数据当成空闲。

日期改变或离开页面时取消旧请求；结果按日期隔离，旧请求不得覆盖新日期。自动刷新在上次请求完成60秒后启动，避免慢请求与定时任务重叠。后台缓存仍为60秒，不延长新鲜度；刷新时清空旧结果，失败时提示并保留学校官方入口，不将过期数据继续标为空闲。

后端缓存锁只保护字典读写，不包裹网络调用。同日期并发通过Future合并为一次采集，成功及失败结果均传递给等待者，失败后可以重试；不同日期和已有缓存不被另一日期的慢请求阻塞。单次采集使用共享httpx.Client复用连接，学校请求仍分小批、最多3个并发，保留原有校历、完整性及字段检查。

验证：109项后端测试、32项前端测试和生产构建通过。新增并发测试覆盖同日合并、不同日期不互相阻塞、缓存有效期、失败不返回过期数据；本地浏览器验证筛选不产生请求、所选节次重算、日期切换及旧响应隔离、手动刷新、失败隐藏旧结果、恢复及手机宽度。

首次读取或缓存过期仍受学校接口及部署网络影响，不能承诺秒开。线上耗时以部署后实测记录为准。
