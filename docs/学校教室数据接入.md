# 学校教室占用查询接入

默认通过学校公开的教室占用每日总览所使用的查询接口读取，不需要学校账号或私人 Cookie。

- 覆盖图文信息楼、教学楼 A–D、古北综合楼。
- 教室目录、座位、日期占用均使用学校返回值；不导出教师工号、姓名或课程详情。
- 第 1–14 节直接对应 JC01–JC14；午间、傍晚分别展示，不挤占节次。
- 按日期缓存成功快照 60 秒，最多 8 个日期；页面每分钟查询，也可手动重新查询。时间是本平台抓取时间，不代表学校数据库更新时间。
- 先检查学校可查询的校历周，再判断占用。查询错误、未返回必要数据、分页不完整、节次状态缺失时返回 503；不回退到演示结果，不将错误当空闲。
- 课表未占用不保证现场无人或教室开放。官方原页面入口保留。
- AI 的 find_rooms 使用相同数据源，包含来源、抓取时间和失败状态。

仅自动测试通过 SCHOOL_ROOMS_MODE=demo 隔离学校网络；线上默认 school，无需新增环境变量。旧演示占用导入不会覆盖学校查询结果。

本地实际验证：2026-10-17 读取 6 个楼宇、178 间教室；最终线上可用性需发布后验证 Render 到学校的连接。
