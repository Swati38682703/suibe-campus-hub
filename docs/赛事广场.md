# 赛事广场

路由 `/competitions`，首页服务入口、首页推荐条及侧栏均可进入，适配手机单列卡片。支持校内/大型比赛分类、学科方向、报名状态、文字搜索、浏览器本地关注、官方外链，以及截止日期的 ICS 日历导出。没有接入自动通知或自动报名。

## 状态与存储

以 Asia/Shanghai 日期计算截止，截止当天不提前关闭。已超过截止或比赛已结束，显示已截止；缺失截止日期、超过 7 天未复核，显示待核实。页面每分钟刷新本地日期。关注 ID 保存在 localStorage，与课表、餐厅集邮分开；没有账号同步。日历导出不代表定时推送，不设置默认提醒，也不导出未知日期。
