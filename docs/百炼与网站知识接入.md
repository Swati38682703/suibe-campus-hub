# 百炼与网站知识接入

## 已实现

- 赛事页与后端共用 `data/competitions.json`；构建镜像会同时带入这份数据。
- AI 新增 `search_competitions`、`search_dining`、`search_services` 三个只读工具。
- 赛事含报名截止、组队、资格、核验日期、原文和按北京时间计算的状态；不混淆报名与作品提交。
- 食堂读取现有公开菜单及已审核评分，排除旧版示例、待审点评、邮箱、管理凭证和个人照片。
- 办事指南读取网站同源知识记录，保留学校来源链接；未录入事项不推定办理规则。
- 网站资料问题在模型生成前先检索，模型可继续调用工具缩小范围。答案附真实资料链接和对应页面入口。
- 未配置密钥时使用明确标注的离线资料检索；不将离线结果宣称为大模型回答。
- 管理员的浏览器本地演示修改仍不写服务器，因此不会成为其他设备或模型的正式知识。

## 用户操作：百炼免费额度

1. 登录 https://bailian.console.aliyun.com/ ，选择华北2（北京）。用户自行完成账号、服务协议及必要认证。
2. 免费额度页搜索 `qwen-plus`，确认仍有免费额度，并确认“免费额度用完即停”为开启状态。
3. 用户自行在 API Key 页面创建密钥，勿发送聊天或上传 GitHub。
4. 在业务空间管理查看空间 ID；以控制台 API 示例给出的北京 Base URL 为准。

## 现有 Render 服务配置

进入现有服务的 Environment，添加或修改以下三项，保留已有数据库、管理凭证等变量：

| 变量 | 内容 |
| --- | --- |
| LLM_API_KEY | 用户直接在 Render 输入百炼密钥 |
| LLM_MODEL | qwen-plus |
| LLM_BASE_URL | 北京空间的兼容接口根地址，例如 https://业务空间ID.cn-beijing.maas.aliyuncs.com/compatible-mode/v1 |

保存并重新部署后，发送实际问题验证。健康接口显示 llm 仅表示已配置，不代表已经完成真实调用验证。

免费额度开关在百炼账户侧管理；网站代码无法代替该开关。切换模型前必须核对新模型是否有额度和开启用完即停。代码不会在限额失败后改用其他付费模型。遇到 `AllocationQuota.FreeTierOnly` 返回明确额度提示。

## 接口与测试

- `GET /api/competitions`：返回网页共用赛事资料。
- `POST /api/agent/chat`：回答、工具轨迹、来源链接、页面入口。
- 真实模型只读公开资料；用户只有主动勾选分享后，才会将课表用于任务。
- 自动化测试覆盖资料一致性、过期/截止状态、未核实菜单、隐私、模型收到网站上下文、来源引用和额度耗尽。模拟响应不代表真实模型效果。
- 百炼密钥填入后仍需执行真实服务验收：赛事截止与提交日期、文贸三楼用餐限制、六期快递地址、多轮澄清、未知规定及模型调用失败。
